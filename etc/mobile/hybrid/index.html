contoh

Satu komponen, dua platform

React Native
function Counter() {
  const [n, setN] = useState(0);
  return (
    <Button title={`Diklik ${n} kali`}
      onPress={() => setN(n + 1)} />
  );
}
Flutter
class Counter extends StatefulWidget {...}

// di dalam State:
int n = 0;
Widget build(ctx) => ElevatedButton(
  onPressed: () => setState(() => n++),
  child: Text('Diklik $n kali'),
);
Beda bahasa, tapi polanya sama: ubah state, tampilan ikut berubah.

Memanggil fitur native dari kode hybrid

Flutter: MethodChannel
const channel = MethodChannel('toko/battery');

Future<int> batteryLevel() async {
  return await channel.invokeMethod('getLevel');
}
// di sisi Android (Kotlin) / iOS (Swift)
// kita tulis implementasi 'getLevel'
React Native: library siap pakai
import * as Location from "expo-location";

const { status } =
  await Location.requestForegroundPermissionsAsync();
if (status === "granted") {
  const pos = await Location.getCurrentPositionAsync();
}
Fitur umum sudah ada library-nya. Fitur langka harus ditulis native.
