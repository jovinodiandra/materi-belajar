Email dan URL: pakai library validasi.

grup

Mengambil bagian dengan grup bernama

Java
var p = Pattern.compile(
  "(?<year>\\d{4})-(?<month>\\d{2})-(?<day>\\d{2})");
var m = p.matcher("Tanggal: 2026-11-13");
if (m.find()) {
  m.group("year");    // "2026"
  m.group("month");   // "11"
}
JavaScript
const m = "Tanggal: 2026-11-13"
  .match(/(?<year>\d{4})-(?<month>\d{2})/);

m.groups.year;    // "2026"
m.groups.month;   // "11"

// ganti semua: str.replaceAll(/\s+/g, " ")
Grup bernama (?<nama>...) jauh lebih mudah dibaca daripada group(1), group(2).

Regex yang bisa membekukan server (ReDoS)

Pola: ^(a+)+$
→
Input: aaaa…aaaa!
→
Mesin mencoba jutaan kombinasi
→
CPU 100% berdetik-detik
  • Hindari kuantifier bertumpuk seperti (a+)+ atau (.*)*.
  • Batasi panjang input sebelum dicocokkan.
praktik

Kebiasaan sehat dengan regex

  • Uji di regex101.com: ada penjelasan tiap bagian.
  • Tulis unit test berisi contoh cocok dan tidak cocok.
  • Untuk email, URL, tanggal: pakai validator library, bukan regex buatan sendiri.
  • Compile sekali, pakai berkali-kali (simpan Pattern sebagai konstanta).
