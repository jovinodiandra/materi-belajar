inti bisnis + colokan yang bisa diganti

◆ Buat apa ini? Kenapa pakai ini?

Given — logika bisnis perlu bicara dengan database, HTTP, dan message broker.

When — logika bisnis memanggil teknologi itu secara langsung.

Then — ganti teknologi berarti membongkar bisnis, dan tes jadi lambat.

→ makanya kita pakai Hexagonal — supaya inti bisnis bebas dari detail teknologi.

Inti bicara ke port, bukan ke JPA

✗ Inti bisnis (tanpa framework)
// port keluar, milik inti
public interface OrderRepository {
    void save(Order order);
}
// use case di inti
public class PlaceOrder {
    private final OrderRepository repo;
    public void handle(Cart cart) {
        var order = Order.from(cart); // aturan
        repo.save(order);
    }
}
✓ Adapter (pinggir, pakai JPA)
@Repository
class JpaOrderRepository
        implements OrderRepository {
    private final OrderJpa jpa;
    public void save(Order o) {
        jpa.save(OrderEntity.from(o));
    }
}
// mau pindah ke Mongo?
// tulis adapter baru, inti tidak berubah
Saat tes: pakai adapter in-memory. Tanpa database, super cepat.
