cara mengatasi

Yang bisa kita lakukan

  • Aktifkan GC log: -Xlog:gc* supaya tahu berapa lama pause-nya.
  • Kurangi bikin objek sementara di jalur yang sering dipanggil (loop besar).
  • Pilih GC modern: G1 (default) atau ZGC untuk pause sangat kecil.
  • Kalau memori penuh terus, curigai memory leak, bukan setting GC.
Jangan langsung utak-atik setting GC. Ukur dulu dari GC log.
baca log GC

Membaca log GC

jalankan dengan
java -Xlog:gc*:file=gc.log:time,uptime \
     -XX:+UseG1GC -Xmx2g -jar app.jar
contoh isi log
[12.345s] GC(41) Pause Young (Normal)
          512M->128M(2048M) 18.2ms     ← normal
[98.765s] GC(57) Pause Full (Allocation Failure)
          2040M->1990M(2048M) 4321.0ms  ← masalah!
# Full GC 4 detik, dan memori hampir tidak turun
# → heap penuh oleh objek yang masih dipakai
Full GC yang lama dan memori yang tidak turun = kemungkinan memory leak.
