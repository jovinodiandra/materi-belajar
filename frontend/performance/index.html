◆ Buat apa ini? Kenapa pakai ini?

Given — user membuka halaman dari berbagai perangkat dan jaringan.

When — kita mengirim JS dan gambar terlalu besar tanpa pernah mengukur.

Then — halaman lambat, user pergi, dan peringkat Google turun.

→ makanya kita pakai optimasi performa yang terukur — supaya halaman cepat di perangkat user sungguhan.
