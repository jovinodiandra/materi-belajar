State Machines

Daftar keadaan yang mungkin, dan aturan pindah dari satu keadaan ke keadaan lain. Kondisi yang mustahil jadi benar-benar mustahil.

$ Lampu lalu lintas: merah → hijau → kuning → merah. Tidak bisa loncat sembarangan.

isLoading dan isError sama-sama true. Layar menampilkan spinner dan error sekaligus.

🚩

Banyak boolean

isLoading, isError, isSuccess, isEmpty.

🤯

Kombinasi mustahil

4 boolean = 16 kombinasi. Yang masuk akal cuma 4.

🐞

Bug tampilan aneh

Spinner dan pesan error tampil bersamaan.

Satu status

hanya satu keadaan dalam satu waktu

◆ Buat apa ini? Kenapa pakai ini?

Given — komponen punya beberapa keadaan seperti memuat, sukses, dan gagal.

When — keadaan itu diwakili beberapa boolean terpisah.

Then — muncul kombinasi mustahil dan tampilan aneh.

→ makanya kita pakai state machine — supaya hanya ada satu keadaan yang sah dalam satu waktu.

tanpa library

State machine sederhana dengan reducer

aturan pindah
const machine = {
  idle:    { FETCH: "loading" },
  loading: { OK: "success", FAIL: "error" },
  success: { FETCH: "loading" },
  error:   { RETRY: "loading" },
};
function reducer(state, event) {
  return machine[state][event] ?? state;
}
pemakaian
const [status, send] = useReducer(reducer, "idle");

send("FETCH");   // idle → loading
send("RETRY");   // diabaikan: loading
                 // tidak punya RETRY

// tombol "Coba lagi" hanya tampil
// kalau status === "error"
Event yang tidak terdaftar diabaikan. Kombinasi mustahil tidak bisa terjadi.
