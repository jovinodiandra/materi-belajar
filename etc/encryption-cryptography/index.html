warm-up

Hashing, enkripsi, atau encoding?

Pilih yang tepat:

  • Menyimpan password user
  • Menyimpan nomor KTP yang nanti perlu dibaca lagi
  • Mengirim gambar di dalam JSON
  • Mengecek file download tidak rusak
contoh

Menyimpan password

✗ Salah
// MD5 / SHA-256 polos: terlalu cepat ditebak
String h = sha256(password);
// atau lebih parah:
user.setPassword(password);   // teks asli!
✓ Benar
PasswordEncoder enc = new BCryptPasswordEncoder(12);

String hash = enc.encode(rawPassword);  // simpan ini
// "$2a$12$Kd9...": salt sudah di dalamnya

boolean ok = enc.matches(input, hash);  // saat login
Password: bcrypt / argon2 (sengaja lambat), bukan MD5/SHA polos.

contoh

Hash password yang benar

Spring Security
PasswordEncoder enc = new BCryptPasswordEncoder(12);

// daftar
user.setPasswordHash(enc.encode(rawPassword));

// login
boolean ok = enc.matches(rawPassword,
                         user.getPasswordHash());
