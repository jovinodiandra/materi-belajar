◆ Buat apa ini? Kenapa pakai ini?

Given — kita ingin antarmuka terasa hidup dan jelas.

When — animasi dibuat tanpa memikirkan performa dan kenyamanan.

Then — animasi patah-patah, mengganggu, bahkan membuat pusing.

→ makanya kita pakai animasi yang tepat — supaya gerakan halus dan membantu user.

warm-up

Animasi ini membantu atau mengganggu?

Nilai masing-masing: membantu 👍 atau mengganggu 👎

  • Keranjang bergoyang sedikit saat barang ditambah.
  • Logo berputar terus di pojok layar.
  • Modal muncul pelan dari tengah dalam 200 ms.
  • Setiap kartu memantul saat halaman dibuka, satu per satu selama 3 detik.
ide dasar

Animasikan transform, bukan posisi

✗ Patah-patah
.panel {
  transition: left 300ms, width 300ms;
}
.panel.open { left: 0; width: 320px; }
/* browser hitung ulang layout tiap frame */
✓ Halus
.panel {
  transition: transform 300ms ease-out,
              opacity 300ms;
}
.panel.open { transform: translateX(0); opacity: 1; }

@media (prefers-reduced-motion: reduce) {
  .panel { transition: none; }
}
Animasikan transform & opacity. Hormati prefers-reduced-motion.
panduan

Panduan animasi UI

durasi

150–300 ms

Cukup terlihat, tidak membuat menunggu.

tujuan

Beri petunjuk

Menunjukkan asal-usul, perubahan, atau status.

easing

ease-out untuk masuk

Cepat di awal, melambat di akhir. Terasa alami.

hindari

Animasi yang menghalangi

User tidak boleh menunggu animasi selesai untuk bekerja.

hormati user

prefers-reduced-motion

CSS
.card { transition: transform 250ms ease-out; }

@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
JavaScript
const reduce = matchMedia(
  "(prefers-reduced-motion: reduce)").matches;

el.animate(frames, {
  duration: reduce ? 0 : 250,
});
Sebagian orang pusing melihat gerakan. Sistem operasi punya pengaturan untuk itu.
