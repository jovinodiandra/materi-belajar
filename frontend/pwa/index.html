◆ Buat apa ini? Kenapa pakai ini?

Given — user memakai produk kita di HP dengan sinyal yang tidak stabil.

When — website hanya bekerja saat online dan tidak bisa dipasang.

Then — user pergi, atau kita harus membuat aplikasi native yang mahal.

→ makanya kita pakai PWA — supaya website bisa dipasang dan tetap berguna saat offline.

ide dasar

Tiga bahan PWA

bahan 1

HTTPS

Wajib. Tanpa HTTPS tidak bisa jadi PWA.

bahan 2

Web App Manifest

File JSON: nama, ikon, warna, cara tampil. Membuat bisa dipasang.

bahan 3

Service Worker

Script di latar belakang yang bisa menyimpan cache dan bekerja offline.

contoh

Service worker: cache sederhana

// sw.js
self.addEventListener("install", (e) => {
  e.waitUntil(caches.open("v1").then((c) =>
    c.addAll(["/", "/app.css", "/app.js", "/offline.html"])));
});

self.addEventListener("fetch", (e) => {
  e.respondWith(
    fetch(e.request).catch(() =>           // online dulu
      caches.match(e.request)              // gagal? ambil cache
        .then((r) => r ?? caches.match("/offline.html"))));
});

Gampangnya

  • Saat dipasang: simpan file penting ke cache.
  • Saat ada request: coba internet dulu.
  • Gagal? Pakai cache, atau tampilkan halaman offline.
Di praktik pakai Workbox atau plugin PWA. Hati-hati versi cache.
