Astro

Framework untuk situs yang banyak kontennya. Default-nya kirim HTML saja, tanpa JavaScript. Bagian interaktif dipasang seperlunya sebagai “pulau”.

$ Halaman statis, dengan pulau-pulau interaktif.

Blog sederhana mengirim 300 KB JavaScript, padahal isinya cuma teks.

📄

Isinya kebanyakan teks

Artikel, gambar, sedikit tombol.

📦

Tapi kirim framework utuh

Seluruh halaman jadi aplikasi JS.

🐢

Lambat di HP

Skor Lighthouse rendah.

Pulau interaktif

JS hanya untuk bagian yang butuh

◆ Buat apa ini? Kenapa pakai ini?

Given — situs kita kebanyakan berisi konten statis.

When — seluruh halaman dibangun sebagai aplikasi JavaScript.

Then — halaman berat dan lambat padahal tidak perlu.

→ makanya kita pakai Astro — supaya hanya bagian interaktif yang membawa JavaScript.

ide dasar

Halaman Astro dengan satu pulau React

---
// berjalan saat build / di server
import Cart from "../components/Cart.jsx";
const posts = await getPosts();
---
<h1>Blog Kami</h1>
{posts.map(p => <article><h2>{p.title}</h2></article>)}

<!-- hanya ini yang membawa JavaScript -->
<Cart client:visible />

Gampangnya

  • Bagian antara --- jalan di server.
  • Sisanya jadi HTML statis.
  • client:visible = muat JS saat komponen terlihat.
  • Bisa pakai React, Vue, Svelte bersamaan.
Tanpa client:* = nol JavaScript.

directive

Kapan pulau dinyalakan?

directive client:*
<Header />                      <!-- HTML saja -->
<Search client:load />          <!-- langsung -->
<Comments client:visible />     <!-- saat terlihat -->
<Chat client:idle />            <!-- saat browser santai -->
<Map client:media="(min-width: 800px)" />
artinya
client:load    → JS dimuat segera
client:visible → dimuat saat di-scroll
client:idle    → setelah halaman tenang
tanpa client:  → HTML statis, 0 JS
Default-nya tanpa JavaScript. Kita yang memilih mana yang perlu interaktif.

praktik

Tips Astro

  • Boleh campur React, Vue, Svelte dalam satu proyek.
  • Mulai statis. Tambah output: "server" hanya kalau butuh data per request.
  • Pakai <Image /> bawaan untuk optimasi gambar otomatis.
  • Ukur dengan Lighthouse: target skor performa 90+.
