Linking Words & Connectors

Ini materi terakhir Level 3. Sejauh ini kamu sudah bisa bikin kalimat lengkap satu-satu — present perfect, passive voice, conditional. Sekarang saatnya menyambungkannya. Because, although, however, so, dan therefore adalah "lem" yang mengubah kumpulan kalimat pendek jadi tulisan yang mengalir dan masuk akal — persis seperti PR description atau incident report yang enak dibaca, bukan sekadar daftar fakta yang ditempel-tempel.

01 Tujuan pembelajaran

Apa yang akan kamu kuasai

Setelah materi ini selesai, kamu akan bisa:

// kategori

Membedakan 3 jenis connector

Subordinating conjunction (because, although), coordinating conjunction (so), dan conjunctive adverb (however, therefore) — tiga kategori dengan aturan tanda baca berbeda.

// makna

Menulis sebab & kontras dengan tepat

Membedakan because (+ klausa) dari because of (+ kata benda), dan although dari however walau artinya mirip.

// tanda baca

Memakai koma & titik koma yang benar

Menghindari comma splice — kesalahan tanda baca paling umum saat memakai however dan therefore.

// dunia kerja

Menulis PR description & incident report yang mengalir

Menyusun laporan kerja, commit message, dan changelog yang terasa seperti tulisan orang berpikir runtut — bukan daftar bullet yang ditempel jadi satu.

02 Konsep inti

Tiga jenis "lem kalimat"

Lima kata yang kita bahas hari ini kelihatannya mirip semua — sama-sama menyambungkan ide — tapi mereka terbagi jadi tiga kategori gramatikal berbeda, dan tiap kategori punya aturan tanda baca sendiri. Ini bagian paling penting dari materi ini.

KategoriContohPosisiTanda baca
Subordinating conjunctionbecause, although, even thoughAwal kalimat atau di tengah, menempel ke klausa alasan/kontrasKoma kalau klausa ini di awal kalimat; tanpa koma kalau di tengah
Coordinating conjunctionsoSelalu di tengah, menyambung dua klausa yang sama-sama bisa berdiri sendiriSelalu didahului koma sebelum so
Conjunctive adverbhowever, thereforeAwal kalimat baru, atau setelah titik komaTitik koma / titik sebelumnya, koma sesudahnya

Because — menjelaskan alasan. Klausanya bisa di depan atau belakang. Because the server crashed, we couldn't deploy. (koma dipakai karena klausa alasan di depan) sama dengan We couldn't deploy because the server crashed. (tanpa koma karena klausanya di belakang).

◆
Jangan tertukar because dan because of. Because diikuti klausa lengkap (subjek + kata kerja): because the server crashed. Because of diikuti kata benda / frasa benda saja, tanpa kata kerja: because of the server crash, because of high traffic.

Although / even though — menunjukkan kontras dalam satu kalimat. Sama seperti because, klausanya bisa di depan atau belakang. Although the docs are outdated, the API itself works fine. atau The API itself works fine although the docs are outdated. Even though punya arti sama, sedikit lebih kuat/formal.

So — menunjukkan hasil, menyambung dua kalimat penuh. Berbeda dari because/although, so menyambungkan dua klausa yang sama-sama independen (masing-masing bisa jadi kalimat sendiri), dan selalu didahului koma. The tests failed, so we rolled back the release.

However / therefore — kontras & hasil antar-kalimat, lebih formal. Keduanya juga menyambung dua klausa independen, tapi tidak boleh dianggap seperti so — mereka butuh titik koma atau titik sebelumnya, bukan cuma koma. The build passed; however, the tests failed. atau dua kalimat terpisah: The build passed. However, the tests failed.

◆ Kesalahan paling umum di kategori ini

Menulis The build passed, however the tests failed. — ini disebut comma splice: memakai koma saja untuk menyambung dua kalimat penuh padahal however butuh titik koma atau titik. Kita bahas tuntas di bab 08.

03 Kenapa penting

Kenapa materi ini penting

Tanpa connector, tulisanmu akan terdengar seperti daftar fakta lepas — benar secara grammar, tapi tidak menunjukkan hubungan logis antar ide. Bandingkan dua versi ini:

✕ Tanpa connector (choppy)

  • The API changed. We updated the client. Some tests still fail. We are investigating.

✓ Dengan connector (mengalir)

  • Because the API changed, we updated the client. However, some tests still fail, so we are investigating.
◆ Kenapa ini krusial buat developer

PR description, incident report, commit message, dan changelog semuanya butuh alur sebab-akibat yang jelas. Reviewer atau on-call engineer lain harus bisa mengikuti kenapa kamu melakukan sesuatu, bukan cuma apa yang kamu lakukan. Connector adalah alat paling efisien untuk itu.

04 Contoh

Contoh sederhana

Satu kalimat contoh untuk masing-masing kata sambung — perhatikan tanda bacanya baik-baik.

  • I stayed home because it was raining. — Saya tinggal di rumah karena hujan.
  • Although it was raining, we went out. — Walaupun hujan, kami tetap keluar.
  • She studied hard, so she passed the exam. — Dia belajar keras, jadi dia lulus ujian.
  • The plan sounds good; however, it is expensive. — Rencananya kedengaran bagus; namun, mahal.
  • He was tired; therefore, he went to bed early. — Dia lelah; oleh karena itu, dia tidur lebih awal.
05 Konteks nyata

Contoh dalam kehidupan sehari-hari

Situasi harian yang mungkin kamu alami:

  • Cerita ke teman kenapa telat: "I was late because the train was delayed." (Saya telat karena keretanya delay.)
  • Menjelaskan rencana berubah: "We wanted to go hiking, but it rained, so we stayed in instead." (Kami mau hiking, tapi hujan, jadi kami di rumah saja.)
  • Mengeluh sopan tentang makanan: "The food was good; however, the service was slow." (Makanannya enak; tapi, pelayanannya lambat.)
  • Menjelaskan keputusan: "Although the apartment is small, it is close to my office." (Walaupun apartemennya kecil, dekat dengan kantor saya.)
◆ Perhatikan

Dalam percakapan santai, orang sering pakai but menggantikan however — lebih pendek dan tidak perlu titik koma. However lebih sering muncul di tulisan formal atau presentasi.

06 Konteks nyata

Contoh dalam dunia kerja

  • Email ke klien: "The project is on schedule; however, we need your feedback on the mockups by Friday."
  • Standup update: "I finished the login feature, so I am starting on the payment flow today."
  • Menjelaskan keterlambatan ke manager: "We couldn't ship on time because of a critical bug found during QA."
  • Proposal ke tim: "Although migrating to the new framework takes time, it will reduce maintenance cost significantly."

Perhatikan bagaimana connector membuat kalimat kerja terdengar lebih profesional — bukan cuma menyatakan fakta, tapi juga menunjukkan bahwa kamu berpikir tentang implikasinya.

07 Konteks nyata

Contoh dalam software engineering

Ini bagian yang paling relevan buat kerjaanmu sehari-hari — connector muncul di commit message, PR description, changelog, dan incident report.

PULL_REQUEST.mdMD
## Summary

The payment webhook was failing intermittently because the retry
logic did not handle timeout errors correctly. Although the fix is
small, it required updating the shared HTTP client used by three
other services, so please review the changes to `http-client.ts`
carefully. Unit tests pass; however, the integration tests are
still running in CI.

Contoh lain dari commit message dan changelog:

  • "Refactor auth middleware because the old implementation caused race conditions."
  • "BREAKING CHANGE: renamed `userId` to `accountId`; therefore, update all API calls accordingly."
  • "The migration script works locally; however, it has not been tested against the staging database yet."
◆ Di incident report

"The outage occurred because a config change was deployed without a rollback plan. The team restored service within 20 minutes, so customer impact was minimal. Although the root cause is now fixed, we are adding automated config validation to prevent recurrence." Perhatikan bagaimana empat kalimat itu terasa seperti satu cerita utuh, bukan daftar kejadian lepas.

08 Awas salah

Kesalahan yang sering dilakukan

Empat kesalahan paling umum — hampir semuanya soal tanda baca, bukan soal makna.

Kesalahan #1 — Comma splice dengan however/therefore. Memperlakukan however/therefore seperti but/so, padahal mereka butuh titik koma atau titik, bukan cuma koma.

salah — comma splice✕ SALAH
The tests passed, however the build failed.
He was tired, therefore he left early.
benar — titik koma / titik✓ BENAR
The tests passed; however, the build failed.
He was tired; therefore, he left early.

Kesalahan #2 — Lupa koma sebelum "so".

salah — tanpa koma✕ SALAH
The API changed so we updated the client.
benar — koma sebelum "so"✓ BENAR
The API changed, so we updated the client.

So sebagai coordinating conjunction selalu didahului koma — sama seperti and/but di FANBOYS.

◆
Kesalahan #3 — Tertukar because dan because of. ❌ We were late because of the traffic was heavy. — salah, karena because of tidak boleh diikuti klausa (subjek + kata kerja). Yang benar: because the traffic was heavy (klausa) atau because of the heavy traffic (kata benda saja).
◆ Kesalahan #4 — Memakai dua penanda kontras sekaligus

❌ Although the tests passed, but the build failed. — although dan but sama-sama menandai kontras, jadi memakai keduanya itu berlebihan (redundant). Pilih salah satu: Although the tests passed, the build failed. atau The tests passed, but the build failed.

09 Cara mengingat

Tips mengingat materi

  • Uji "bisa berdiri sendiri?" — kalau kedua sisi kalimat bisa jadi kalimat lengkap masing-masing, itu tandanya kamu butuh so/however/therefore (dengan koma atau titik koma yang tepat), bukan because/although.
  • "So butuh koma, however butuh titik koma." — jembatan keledai pendek untuk aturan tanda baca paling sering salah.
  • Because nempel ke alasan, although nempel ke kontra — keduanya fleksibel posisinya (boleh di depan/belakang kalimat), beda dari so/however/therefore yang posisinya lebih kaku (selalu di antara dua klausa/kalimat).
  • Because of = kata benda, because = klausa — kalau setelah kata itu ada subjek + kata kerja, pakai because; kalau cuma kata benda, pakai because of.

Grammar bukan aturan sewenang-wenang — ia mencerminkan bagaimana pikiran manusia menyusun sebab-akibat. Kalau kamu paham logikanya, tanda bacanya jadi masuk akal, bukan sekadar dihafal.

— prinsip dasar linguistik fungsional

Latihan paling efektif: setiap kali menulis PR description atau incident report, coba secara sadar pakai satu because, satu however/therefore, dan satu so — lama-lama otomatis.

10 Ringkasan

Ringkasan materi

  • Because / although / even though — subordinating conjunction, fleksibel posisinya, koma hanya kalau klausanya di depan.
  • So — coordinating conjunction, selalu didahului koma, menyambung dua klausa independen.
  • However / therefore — conjunctive adverb, butuh titik koma atau titik sebelumnya, koma sesudahnya.
  • Because of — diikuti kata benda, bukan klausa; beda dari because.

14 Praktik

Writing exercise

Tulis satu paragraf pendek (5-7 kalimat) menceritakan hari kerjamu baru-baru ini — masalah yang muncul, kenapa terjadi, dan bagaimana kamu menyelesaikannya. Wajib memakai minimal satu dari tiap kategori:

  • Satu because atau although/even though — subordinating conjunction.
  • Satu so — coordinating conjunction, ingat komanya.
  • Satu however atau therefore — conjunctive adverb, ingat titik koma/titiknya.
◆ Kirimkan hasilnya

Kirimkan hasil tulisanmu di chat kapan saja — akan dikoreksi grammar dan tanda baca connector-nya sebelum kamu lanjut ke Cerita Hari Ini Level 3.

15 Praktik

Speaking exercise

Ucapkan keras-keras (boleh rekam suara sendiri untuk didengar ulang), perhatikan jeda sebelum however/therefore:

  1. "I was late because the meeting ran long."
  2. "Although the deadline is tight, we can still make it."
  3. "The demo went well, so the client seemed happy."
  4. "The feature works locally. However, we still need to test it in staging."
  5. "The server crashed. Therefore, we rolled back the deployment."

Perhatikan jeda napas alami di depan however dan therefore ketika mereka memulai kalimat baru — jeda itu "menggantikan" titik koma/titik yang kamu tulis.

17 Perkaya bacaan

Reading recommendation

"The service was slow during peak hours because the database connection pool was too small. Although we increased the pool size temporarily, the underlying issue was inefficient queries. Therefore, the team is now refactoring the query layer; however, this will take another sprint to complete."

Paragraf pendek ini sengaja dipadatkan dengan lima connector supaya kamu latihan mengenali polanya dalam teks utuh, bukan cuma kalimat lepas.

Kalau sudah lancar, coba baca bagian "Postmortem" atau "Root Cause Analysis" dari incident report perusahaan-perusahaan tech besar (banyak yang dipublikasikan sebagai blog post) — genre tulisan itu penuh connector sebab-akibat seperti yang kita pelajari.

18 Perkaya kosakata

Vocabulary list (20 kata)

Untuk materi ini, vocabulary-nya adalah connector-connector itu sendiri, plus beberapa sinonim yang sering muncul di tulisan formal. Familiar dulu — makin sering dipakai, makin nempel.

because/bɪˈkɔːz/karena

subordinating conj. — Contoh: "We rolled back because the deploy failed." Diikuti klausa lengkap.

because of/bɪˈkɔːz əv/karena (+ kata benda)

preposition — Contoh: "Delayed because of the outage." Diikuti kata benda, bukan klausa.

since/sɪns/karena (formal, causal)

subordinating conj. — Contoh: "Since the tests pass, we can merge." Sinonim dari because di konteks ini.

as/æz/karena (causal, formal)

subordinating conj. — Contoh: "As the team was short-staffed, the release was delayed."

although/ɔːlˈðoʊ/walaupun

subordinating conj. — Contoh: "Although it's risky, we'll proceed."

even though/ˈiːvən ðoʊ/meskipun (lebih kuat)

subordinating conj. — Contoh: "Even though we tested it twice, a bug slipped through."

though/ðoʊ/meskipun (informal)

conjunction / adverb — Contoh: "It works. It's slow, though." Bisa diletakkan di akhir kalimat, gaya santai.

but/bʌt/tapi

coordinating conj. — Contoh: "It's fast, but it's not accurate." Versi kasual dari however.

however/haʊˈevər/namun / meskipun begitu

conjunctive adverb — Contoh: "It's fast; however, it's not accurate." Butuh titik koma/titik.

nevertheless/ˌnevərðəˈles/meskipun demikian

conjunctive adverb — Contoh: "The task is hard; nevertheless, we'll finish it." Lebih formal dari however.

nonetheless/ˌnʌnðəˈles/walaupun begitu

conjunctive adverb — Contoh: "Progress is slow; nonetheless, we're moving forward." Sinonim nevertheless.

so/soʊ/jadi / sehingga

coordinating conj. — Contoh: "The build failed, so we rolled back." Selalu didahului koma.

therefore/ˈðerfɔːr/oleh karena itu

conjunctive adverb — Contoh: "The API changed; therefore, clients must update." Lebih formal dari so.

thus/ðʌs/demikian / dengan begitu

conjunctive adverb — Contoh: "The cache was stale, thus causing incorrect results." Sangat formal, umum di tulisan akademik.

consequently/ˈkɒnsɪkwəntli/akibatnya

conjunctive adverb — Contoh: "Traffic spiked; consequently, the server ran out of memory."

despite/dɪˈspaɪt/walaupun (+ kata benda)

preposition — Contoh: "Despite the bug, the release shipped on time." Diikuti kata benda, seperti because of.

in spite of/ɪn spaɪt əv/walaupun (+ kata benda)

preposition — Contoh: "In spite of the delay, the client was satisfied." Sinonim despite, sedikit lebih panjang.

whereas/werˈæz/sedangkan

subordinating conj. — Contoh: "The old API returns XML, whereas the new one returns JSON." Untuk membandingkan dua hal, bukan sekadar kontras.

moreover/mɔːrˈoʊvər/selain itu / lebih lanjut

conjunctive adverb — Contoh: "The fix is simple; moreover, it improves performance too." Untuk menambahkan poin, bukan kontras/hasil.

furthermore/ˈfɜːrðərmɔːr/selanjutnya / lagipula

conjunctive adverb — Contoh: "The new library is faster; furthermore, it has better documentation." Sinonim moreover.

19 Perkaya ucapan

Pronunciation tips

  • although /ɔːlˈðoʊ/ — tekanan di suku kata kedua ("oʊ" seperti "oh" yang panjang). Bunyi "th" pakai lidah menyentuh gigi atas, bukan seperti "t" dalam Bahasa Indonesia.
  • however /haʊˈevər/ — tekanan di suku kata kedua ("EV"), bukan di awal. Sering diucapkan dengan jeda kecil sebelum dan sesudahnya karena ia menandai transisi ide.
  • therefore /ˈðerfɔːr/ — tekanan di suku kata pertama, beda dari however. "th" di awal juga pakai lidah menyentuh gigi.
  • because /bɪˈkɔːz/ — tekanan di suku kata kedua, sering "diperpendek" jadi "'cause" /kɔːz/ dalam percakapan sangat santai (hindari di tulisan formal).
◆ Jeda sebagai tanda baca lisan

Saat bicara, jeda napas pendek sebelum however/therefore berfungsi seperti titik koma di tulisan — pendengar "mendengar" transisi ide itu lewat jeda, bukan lewat kata sambung semata. Latih ini di bagian Speaking Exercise.

Kuasai dulu materi ini

Target minimum sebelum membuka Cerita Hari Ini Level 3 — semua ada di checklist bab Review.

  • Hafal tiga kategori: subordinating (because/although), coordinating (so), conjunctive adverb (however/therefore).
  • Paham aturan tanda baca tiap kategori, terutama comma splice pada however/therefore.
  • Bisa bedakan because dari because of.
  • Kenali & hindari 4 kesalahan umum di bab 08.
⚙ Middle

Praktikkan di kehidupan nyata

Setelah hafal aturan, pindahkan ke tulisan kerja asli — bukan cuma soal latihan.

  • Pakai connector secara sadar di PR description & commit message berikutnya.
  • Coba tulis ulang satu incident report/README lama supaya lebih mengalir pakai connector.
  • Latih dengar lewat rekomendasi di bab Listening (TED Talks, Software Engineering Daily).
  • Cari contoh however/therefore di blog post engineering perusahaan besar untuk kalibrasi rasa bahasa.
🚀 Advance

Arah belajar lanjut

Setelah checklist Materi 5 tuntas, ini gerbang berikutnya.

  • Cerita Hari Ini Level 3 — tulis cerita gabungan seluruh materi Level 3, syarat membuka Level 4.
  • Setelah lolos, lanjut ke Level 4: Bicara Seperti Native — Past Perfect, Reported Speech, Third Conditional, Relative Clauses.
  • Terus biasakan menulis PR description/incident report dengan connector yang tepat — ini kebiasaan yang dipakai seumur karier.
Penutup

Lem yang menyatukan seluruh Level 3

Materi 5 selesai — dan dengan itu, seluruh materi Level 3 tuntas. Kamu sudah menguasai present perfect, passive voice, conditional, dan sekarang cara menyambungkan semuanya jadi tulisan yang mengalir. Jangan buru-buru; pastikan checklist di bab Review benar-benar tuntas sebelum membuka gerbang berikutnya.

  • Because / although — subordinating conjunction, fleksibel posisinya.
  • So — coordinating conjunction, selalu didahului koma.
  • However / therefore — conjunctive adverb, butuh titik koma atau titik.
  • Rangkai jadi cerita — sebab-akibat yang jelas bikin tulisan kerja terasa profesional.

Level 3 · Materi 5 dari 5 — Level 3 tuntas!

Cerita Hari Ini Level 3 (gerbang ke Level 4) terkunci sampai semua soal Latihan & Quiz di bab 11-12 benar. Kirim hasil Writing Exercise-mu kapan saja — bagian yang belum kuat akan diulang dulu sebelum lanjut.
