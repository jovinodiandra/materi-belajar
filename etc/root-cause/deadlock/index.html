Deadlock

Dua proses saling nunggu. A nunggu B, B nunggu A. Hasilnya: dua-duanya diam selamanya.

$ Dua mobil di jembatan sempit, tidak ada yang mau mundur.

kejadiannya

Gimana deadlock terjadi

A kunci Akun 1
→
B kunci Akun 2
→
A minta Akun 2 → nunggu
→
B minta Akun 1 → nunggu
  • Tidak ada yang mau melepas kunci duluan.
  • Hasilnya: macet selamanya, sampai ada yang dipaksa berhenti.
contoh

Urutan kunci acak vs urutan kunci tetap

✗ Urutan tergantung input
void transfer(Akun dari, Akun ke, int n) {
  synchronized (dari) {
    synchronized (ke) {  // ← A & B bisa saling kunci
      dari.kurang(n); ke.tambah(n);
    }
  }
}
✓ Selalu kunci ID terkecil dulu
void transfer(Akun dari, Akun ke, int n) {
  Akun a = dari.id < ke.id ? dari : ke;
  Akun b = dari.id < ke.id ? ke : dari;
  synchronized (a) {
    synchronized (b) {
      dari.kurang(n); ke.tambah(n);
    }
  }
}
Kalau semua orang kunci dengan urutan yang sama, deadlock tidak bisa terjadi.
