i18n

Internasionalisasi: menyiapkan aplikasi supaya bisa tampil dalam banyak bahasa, format tanggal, mata uang, dan angka.

$ i + 18 huruf + n. Satu aplikasi, banyak negara.

Ekspansi ke Malaysia. Ribuan teks Indonesia tertanam langsung di komponen.

◆ Buat apa ini? Kenapa pakai ini?

Given — aplikasi perlu tampil untuk pengguna dari bahasa dan negara berbeda.

When — teks, angka, dan tanggal ditulis langsung di kode.

Then — menambah bahasa berarti mengubah ratusan file.

→ makanya kita pakai i18n — supaya bahasa baru cukup menambah file terjemahan.

ide dasar

Teks dari kamus, format dari Intl

✗ Ditulis langsung
<p>Kamu punya {count} item</p>
<p>Total: Rp {total}</p>
<p>{d.getDate()}/{d.getMonth()+1}/{d.getFullYear()}</p>
✓ Siap banyak bahasa
// id.json: { "cart.items": "{count, plural, =0 {Keranjang kosong} other {# item}}" }
<p>{t("cart.items", { count })}</p>

new Intl.NumberFormat("id-ID",
  { style: "currency", currency: "IDR" }).format(total);
// "Rp 250.000"

new Intl.DateTimeFormat("id-ID",
  { dateStyle: "long" }).format(d);
// "13 November 2026"
Intl bawaan browser: angka, uang, tanggal sesuai negara.

Kalimat jamak yang benar

kamus (ICU message)
{
  "cart": "{count, plural,
    =0 {Keranjang kosong}
    one {# barang di keranjang}
    other {# barang di keranjang}}"
}
// bahasa Inggris: item / items
// bahasa Arab: 6 bentuk jamak!
pemakaian
t("cart", { count: 0 })  // Keranjang kosong
t("cart", { count: 3 })  // 3 barang di keranjang

// tanggal & uang pakai Intl
new Intl.NumberFormat("id-ID",
  { style: "currency", currency: "IDR" })
  .format(25000)   // Rp 25.000,00
Aturan jamak tiap bahasa berbeda. Biarkan library yang mengurus.

hal penting

Lebih dari sekadar terjemahan

  • Bahasa kanan-ke-kiri (Arab): pakai dir="rtl" dan CSS margin-inline-start.
  • Teks Jerman bisa ±30% lebih panjang. Jangan kunci lebar tombol.
  • Zona waktu: simpan UTC, tampilkan sesuai zona user.
  • Gambar berisi teks juga perlu versi per bahasa.
