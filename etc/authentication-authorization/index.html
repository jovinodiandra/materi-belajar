Dua pertanyaan

siapa kamu? · boleh apa?

◆ Buat apa ini? Kenapa pakai ini?

Given — aplikasi punya data milik banyak user dengan hak berbeda.

When — server hanya mengecek user sudah login, bukan haknya atas data itu.

Then — user bisa membaca atau mengubah data milik orang lain.

→ makanya kita pakai authentication + authorization — supaya setiap akses dicek identitas dan haknya.

Authentication vs Authorization

Authentication (AuthN)Authorization (AuthZ)
PertanyaanKamu siapa?Kamu boleh apa?
ContohLogin password, OTP, Google loginRole admin, pemilik order
Gagal401 Unauthorized403 Forbidden
Alat umumOAuth2 / OIDC, session, JWTRBAC, cek kepemilikan, policy
401 = belum dikenal. 403 = dikenal, tapi tidak boleh.
contoh

Selalu cek kepemilikan di server

✗ Hanya cek login
@GetMapping("/orders/{id}")
Order get(@PathVariable long id) {
    return orderRepo.findById(id).orElseThrow();
    // user mana pun yang login bisa lihat
}
✓ Cek kepemilikan
@GetMapping("/orders/{id}")
Order get(@PathVariable long id,
          @AuthenticationPrincipal User me) {
    return orderRepo.findByIdAndOwnerId(id, me.id())
        .orElseThrow(NotFoundException::new);
    // bukan miliknya? 404, jangan bocorkan keberadaan
}
Bukan miliknya? Balas 404 supaya keberadaannya tidak bocor.
