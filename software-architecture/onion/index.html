Onion Architecture

Kode disusun seperti lapisan bawang. Yang paling penting (domain) ada di tengah. Lapisan luar boleh kenal dalam, tapi tidak sebaliknya.

$ Kupas dari luar, intinya tetap utuh.

Di layered biasa, domain ada di tengah tumpukan dan bergantung ke database.

🏢

Layered: bisnis di atas database

Bisnis harus tahu cara data disimpan.

🔄

Database jadi pusat dunia

Desain dimulai dari tabel, bukan dari aturan bisnis.

🧪

Domain susah dites sendiri

Selalu terseret infrastruktur.

Domain di tengah

semua bergantung ke dalam

◆ Buat apa ini? Kenapa pakai ini?

Given — aturan bisnis adalah bagian paling berharga dari aplikasi.

When — aturan bisnis justru bergantung ke database dan framework.

Then — perubahan teknologi merembet ke domain.

→ makanya kita pakai Onion — supaya domain berada di pusat dan tidak bergantung ke siapa pun.

contoh

Struktur package yang mencerminkan bawang

com.toko.order
  domain/            // lapis 1-2: tanpa framework
    Order.java
    Money.java
    OrderRepository.java   // interface
    PricingService.java
  application/       // lapis 3: use case
    PlaceOrderService.java
  infrastructure/    // lapis 4: teknologi
    JpaOrderRepository.java
    OrderController.java

Gampangnya

  • domain tidak import apa pun dari luar.
  • application cuma import domain.
  • infrastructure boleh import semuanya.
Cek gampang: package domain tidak boleh import Spring atau JPA.

lapis 2

Domain service: aturan yang melibatkan banyak objek

domain/PricingService.java
public class PricingService {
  public Money finalPrice(Order order,
                          Voucher voucher,
                          Customer customer) {
    Money p = order.subtotal();
    if (voucher.isValidFor(customer))
      p = voucher.applyTo(p);
    return p;
  }   // tanpa framework, tanpa database
}
Kenapa tidak di Order?
// Aturan ini melibatkan 3 objek.
// Kalau dipaksa masuk Order,
// Order jadi kenal Voucher & Customer.

// Domain service = tempat netral
// untuk aturan lintas objek.
Lapis 1 menjaga aturan satu objek. Lapis 2 menjaga aturan antar objek.

praktik

Tanda bawangmu sehat

  • Folder domain/ bisa di-compile tanpa Spring di classpath.
  • Tes domain jalan dalam milidetik.
  • Ganti database tidak mengubah satu file pun di domain.
  • Orang bisnis bisa membaca nama kelas di domain dan paham.
