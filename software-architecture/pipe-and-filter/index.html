contoh

Kamu sudah memakainya: Java Stream

✗ Sebelum: satu blok besar
Map<LocalDate, Long> report(List<String> lines) {
    var result = new HashMap<LocalDate, Long>();
    for (var line : lines) {
        var tx = parse(line);
        if (tx == null || tx.amount() <= 0) continue;
        result.merge(tx.date(), tx.amount(), Long::sum);
    }
    return result;
}
✓ Sesudah: rangkaian filter
Map<LocalDate, Long> report(List<String> lines) {
    return lines.stream()
        .map(Parser::parse)             // filter 1
        .filter(Objects::nonNull)       // filter 2
        .filter(tx -> tx.amount() > 0)  // filter 3
        .collect(groupingBy(Tx::date,   // filter 4
                 summingLong(Tx::amount)));
}
Skala besar: Spring Batch, Kafka Streams, pipeline ETL.

Filter sebagai fungsi kecil yang bisa dirangkai

filter-filter kecil
Function<String, Tx> parse = Tx::fromCsv;
Predicate<Tx> valid = tx -> tx.amount() > 0;
Function<Tx, Tx> toIdr = fx::convert;
rangkai jadi pipa
lines.stream()
     .map(parse)
     .filter(valid)
     .map(toIdr)
     .collect(groupingBy(Tx::date,
              summingLong(Tx::amount)));
