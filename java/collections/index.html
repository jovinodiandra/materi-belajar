Java Collections

List, Set, Map, Queue — wadah untuk menyimpan banyak data. Pilih wadah yang tepat, kodemu jadi cepat dan gampang dibaca.

$ Lemari, kotak, dan loker: beda barang, beda wadah.

Semua data dimasukkan ke ArrayList. Mencari satu id harus cek satu-satu.

📋

Karena itu yang pertama kita pelajari.

🐢

Cari data = loop seluruh isi

10.000 data = 10.000 kali cek.

👯

Data dobel tidak sengaja

List mengizinkan isi yang sama masuk berkali-kali.

Given — kita perlu menyimpan banyak data di memori.

contoh

Dari List ke Map: cari jadi instan

✗ Sebelum: cari di List
List<User> users = repo.findAll();

for (Order o : orders) {
    User u = users.stream()   // cek satu-satu
        .filter(x -> x.id().equals(o.userId()))
        .findFirst().orElseThrow();
    print(o, u);
}   // 1.000 order × 1.000 user = sejuta cek
✓ Sesudah: pakai Map
Map<Long, User> byId = repo.findAll().stream()
    .collect(toMap(User::id, u -> u));

for (Order o : orders) {
    User u = byId.get(o.userId());  // langsung
    print(o, u);
}   // 1.000 order = 1.000 ambil langsung
Bangun Map sekali, lalu ambil langsung. Sejuta cek jadi seribu.
yang perlu dijaga

Jebakan yang sering kejadian

jebakan

Lupa equals & hashCode

Objek sendiri di HashSet/HashMap harus punya equals & hashCode. Pakai record.

jebakan

Ubah list sambil di-loop

ConcurrentModificationException. Pakai removeIf().

jebakan

Map biasa di banyak thread

Pakai ConcurrentHashMap kalau diakses banyak thread.

tips

Kembalikan koleksi kosong

Jangan return null. Return List.of().

salah → benar

Objek sendiri di HashSet: wajib equals & hashCode

✗ lupa hashCode
class User {
  String email;
  // tidak ada equals/hashCode   // ← masalahnya
}
set.add(new User("a@x.com"));
set.add(new User("a@x.com"));
set.size();   // 2 — dobel!
✓ pakai record
record User(String email) {}
// record otomatis punya
// equals & hashCode

set.add(new User("a@x.com"));
set.add(new User("a@x.com"));
set.size();   // 1 ✓
HashSet dan HashMap mencari pakai hashCode dulu, baru cek equals.
jebakan klasik

Hapus item sambil looping

for (String n : names) {
  if (n.isBlank()) names.remove(n);   // ← ConcurrentModificationException
}
// ✓ benar:
names.removeIf(String::isBlank);
  • Mengubah list saat sedang dijalani = menggergaji dahan yang kita duduki.
  • Pakai removeIf atau Iterator.remove().

❯ set & map

equals & hashCode, jangan ubah sambil loop.
