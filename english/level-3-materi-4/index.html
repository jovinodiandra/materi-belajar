First & Second Conditional

Sekarang kita belajar bicara tentang "kalau" — bukan cuma "kalau" dalam arti kemungkinan nyata di masa depan ("kalau besok hujan, aku bawa payung"), tapi juga "kalau" yang sifatnya andaian, sesuatu yang belum tentu terjadi atau bahkan tidak mungkin sekarang ("kalau aku jadi kamu, aku akan refactor dulu"). Dua bentuk ini terdengar mirip tapi maknanya beda jauh — dan keduanya sering banget dipakai saat planning sprint, code review, dan diskusi teknis "what if".

01 Tujuan pembelajaran

Apa yang akan kamu kuasai

Setelah materi ini selesai, kamu akan bisa:

// first conditional

Menyusun kalimat kemungkinan nyata

Menyusun If + Simple Present, ... will + V1 untuk membicarakan kemungkinan nyata di masa depan.

// second conditional

Menyusun kalimat andaian

Menyusun If + Simple Past, ... would + V1 untuk membicarakan situasi hipotetis/tidak nyata sekarang.

// makna

Membedakan "mungkin terjadi" vs "andai saja"

Tahu kapan sesuatu masih realistis (first) dan kapan sesuatu cuma bayangan/tidak mungkin (second).

// dunia kerja

Memakainya dalam planning & code review

Memakai conditional untuk membahas skenario "bagaimana kalau", memberi saran teknis, dan merencanakan langkah selanjutnya.

02 Konsep inti

Dua jenis "kalau" yang berbeda

Kalimat conditional (kalimat pengandaian) selalu punya dua bagian: klausa if (syarat) dan klausa hasil (akibat). Yang membedakan first dan second conditional adalah seberapa nyata/mungkin syaratnya itu.

First Conditional — kemungkinan nyata di masa depan. Dipakai kalau syaratnya masih mungkin terjadi, kamu benar-benar membicarakan masa depan yang realistis. Rumusnya:

BagianRumusContoh
If-clause (syarat)If + Simple PresentIf it rains tomorrow,
Main clause (hasil)will + V1I will bring an umbrella.

Lengkapnya: If it rains tomorrow, I will bring an umbrella. — Kalau besok hujan (dan itu memang mungkin terjadi), aku akan bawa payung. Perhatikan: klausa if pakai Simple Present (bukan will), walau maknanya tentang masa depan — ini sering jadi salah kaprah pemula.

Second Conditional — situasi hipotetis/tidak nyata sekarang. Dipakai untuk membayangkan sesuatu yang tidak benar sekarang, atau kecil kemungkinannya terjadi. Rumusnya:

BagianRumusContoh
If-clause (syarat)If + Simple PastIf I had more time,
Main clause (hasil)would + V1I would learn Rust.

Lengkapnya: If I had more time, I would learn Rust. — Kenyataannya sekarang aku tidak punya cukup waktu (itu andaian, bukan fakta), jadi ini cuma bayangan. Perhatikan lagi: klausa if pakai Simple Past (had), tapi artinya bukan masa lalu — ini "past tense untuk hal yang tidak nyata", bukan penanda waktu.

◆ Cara paling gampang membedakan keduanya

Tanyakan: "apakah ini masih mungkin/realistis terjadi?" Kalau ya → First Conditional (if + present, will + V1). Kalau itu cuma khayalan, tidak nyata sekarang, atau kemungkinannya sangat kecil → Second Conditional (if + past, would + V1). Contoh: If I win the lottery, I will buy a house. (mungkin, walau tipis) vs If I won the lottery, I would buy a house. (dibayangkan sebagai hal yang jauh dari kenyataan).

Satu kasus khusus: "if I were". Dalam Second Conditional, untuk kata kerja to be, bentuk yang secara tradisional dianggap benar untuk semua subjek (termasuk I/he/she/it) adalah were, bukan was — ini disebut subjunctive mood. Contoh paling umum: If I were you, I would refactor this function first. ("Kalau aku jadi kamu...") — ungkapan ini sangat sering dipakai untuk memberi saran secara sopan, termasuk saat code review.

◆ Unless = if not

Unless berarti "kecuali" atau "kalau tidak" — bisa dipakai sebagai versi negatif dari if, paling sering di First Conditional. Unless we optimize this query, it will time out. = If we don't optimize this query, it will time out. Dua-duanya benar, tapi unless terdengar lebih ringkas.

Susunan klausa boleh dibalik tanpa mengubah arti — kalau klausa hasil ditaruh duluan, tidak perlu koma: I will bring an umbrella if it rains. = If it rains, I will bring an umbrella.

03 Kenapa penting

Kenapa materi ini penting

Conditional adalah cara utama untuk membicarakan skenario "bagaimana kalau" — dan dunia software engineering penuh dengan skenario semacam itu:

  • Planning sprint: "If we finish the API today, we will start testing tomorrow."
  • Code review yang sopan: "If I were you, I would extract this into a separate function."
  • Risk assessment: "If the third-party service goes down, we will need a fallback."
  • Retrospective bersyarat: "If we had written more tests, we would have caught this bug earlier." (ini masuk Third Conditional — dibahas di Level 4, tapi kamu akan sering dengar sekilas.)
◆ Kenapa ini "menyambung gagasan"

Conditional menghubungkan dua gagasan: syarat dan akibat. Ini kemampuan penting untuk bernalar terbuka dalam Bahasa Inggris — merancang rencana (first conditional) maupun mendiskusikan alternatif yang belum tentu terjadi (second conditional). Tanpa conditional, sulit membahas "apa yang akan terjadi jika..." secara alami.

04 Contoh

Contoh sederhana

Delapan kalimat dasar, campuran First & Second Conditional — perhatikan bedanya.

  • If it rains, I will bring an umbrella. — First — Kalau hujan, aku akan bawa payung.
  • If I had a car, I would drive to work. — Second — Kalau aku punya mobil (tapi sekarang tidak), aku akan naik mobil ke kantor.
  • If you study hard, you will pass the exam. — First — Kalau kamu belajar keras, kamu akan lulus ujian.
  • If I were rich, I would travel the world. — Second — Andai aku kaya, aku akan keliling dunia.
  • Unless we hurry, we will miss the bus. — First — Kalau kita tidak buru-buru, kita akan ketinggalan bus.
  • If she asked, I would help her. — Second — Kalau dia minta tolong (belum tentu), aku akan bantu.
  • If it is sunny tomorrow, we will go hiking. — First — Kalau besok cerah, kita akan hiking.
  • If I knew the answer, I would tell you. — Second — Kalau aku tahu jawabannya (tapi aku tidak tahu), aku akan bilang.
05 Konteks nyata

Contoh dalam kehidupan sehari-hari

Situasi harian yang biasa kamu alami:

  • Ngobrol soal cuaca: "If it doesn't rain this weekend, we will have a picnic." (First — masih mungkin.)
  • Membayangkan hidup lain: "If I lived in Japan, I would eat ramen every week." (Second — cuma bayangan, kenyataannya tidak tinggal di Jepang.)
  • Memberi saran ke teman: "If I were you, I would talk to him directly." (Second — nasihat, bukan fakta.)
  • Rencana akhir pekan: "If my friend comes, we will watch a movie together." (First — masih realistis.)
◆ Perhatikan

Second conditional sering dipakai untuk memberi saran secara sopan — If I were you, ... terdengar jauh lebih halus daripada perintah langsung seperti "You should...".

06 Konteks nyata

Contoh dalam dunia kerja

  • Rencana proyek: "If the client approves the proposal, we will start development next week."
  • Saran ke rekan kerja: "If I were the project manager, I would extend the deadline by a few days."
  • Membahas risiko: "If we don't get more resources, we will miss the launch date."
  • Negosiasi: "If you could offer a better rate, we would consider signing the contract."

Perhatikan bagaimana second conditional sering muncul saat orang ingin terdengar lebih sopan atau tidak langsung — cocok dipakai dalam negosiasi atau memberi masukan ke atasan.

07 Konteks nyata

Contoh dalam software engineering

Ini bagian intinya — conditional adalah bahasa sehari-hari untuk sprint planning, code review, dan diskusi arsitektur.

sprint planningPLANNING
// Diskusi rencana sprint — First Conditional
If the API integration is done today,
we will start testing tomorrow.

If the tests pass, we will deploy to staging.

Unless something changes, we will ship by Friday.

Contoh dari code review (gaya komentar pull request):

  • "If I were you, I would extract this logic into a separate helper function."
  • "If this endpoint were public, we would need rate limiting." (Second — endpoint-nya sebenarnya tidak public.)
  • "If we had more time, we would write more edge-case tests."
risk assessmentRISK
## Risk Notes
If the third-party API goes down,
our checkout flow will fail completely.

// Skenario hipotetis, bukan rencana nyata:
If we didn't rely on a single provider,
we would be more resilient.
◆ Di daily standup

"If the QA team approves it today, we will merge the PR this afternoon. But if I were leading this sprint, I would prioritize the bug fixes first." Perhatikan bagaimana kalimat pertama membahas kemungkinan nyata (First), sementara kalimat kedua cuma pendapat/andaian (Second) — dua conditional dipakai berdampingan secara natural.

08 Awas salah

Kesalahan yang sering dilakukan

Empat kesalahan paling umum — kenali polanya supaya tidak terulang.

Kesalahan #1 — Pakai "will" di klausa if pada First Conditional. Klausa if harus pakai Simple Present, bukan will, walau membicarakan masa depan.

salah — will di klausa if✕ SALAH
If it will rain, I will bring an umbrella.
If the tests will pass, we will deploy.
benar — Simple Present di klausa if✓ BENAR
If it rains, I will bring an umbrella.
If the tests pass, we will deploy.

Kesalahan #2 — Mencampur First & Second Conditional dalam satu kalimat.

salah — rumus tercampur✕ SALAH
If I have money, I would buy a laptop.
If I had money, I will buy a laptop.
benar — konsisten satu jenis✓ BENAR
If I have money, I will buy a laptop.
If I had money, I would buy a laptop.

Pilih satu: kalau memang masih mungkin (First), pakai present+will konsisten. Kalau memang hipotetis (Second), pakai past+would konsisten. Jangan dicampur.

◆
Kesalahan #3 — Lupa "were" untuk ungkapan saran "if I were you". ❌ If I was you, I would fix this first. — dalam Bahasa Inggris formal/tertulis, bentuk baku Second Conditional untuk "to be" adalah were untuk semua subjek, termasuk "I". Dalam percakapan santai, "if I was" memang sering terdengar dan tidak akan bikin orang salah paham — tapi untuk tulisan kerja (email, dokumentasi), pakai were.
◆ Kesalahan #4 — Salah pakai "unless"

❌ Unless we don't optimize this, it will time out. — unless sudah berarti "kalau tidak", jadi tidak boleh ditambah not lagi (itu jadi negatif ganda). Yang benar: Unless we optimize this, it will time out.

09 Cara mengingat

Tips mengingat materi

  • Uji "masih realistis atau tidak?" Kalau iya → First (present + will). Kalau cuma bayangan/andaian/kecil kemungkinannya → Second (past + would).
  • Pasangan yang tidak boleh tertukar: present + will (First), past + would (Second). Jangan pernah campur present + would atau past + will dalam satu kalimat conditional biasa.
  • "If I were you" = jembatan saran sopan. Setiap kali mau kasih saran halus ke rekan kerja, coba pakai frasa ini sebagai pembuka.
  • Unless = "kalau tidak", jangan tambah "not" lagi — anggap unless sudah membawa arti negatif di dalamnya sendiri.

Conditional bukan sekadar rumus tata bahasa — dia cara kita menimbang kemungkinan sebelum mengambil keputusan.

— prinsip umum penggunaan "if clauses" dalam Bahasa Inggris

Artinya: setiap kali kamu ragu pakai First atau Second, tanyakan pada dirimu sendiri "seberapa yakin aku ini bisa/akan terjadi?" Kalau cukup yakin — First. Kalau ragu, tidak nyata, atau cuma perumpamaan — Second.

10 Ringkasan

Ringkasan materi

  • First Conditional — If + Simple Present, ... will + V1 — kemungkinan nyata di masa depan.
  • Second Conditional — If + Simple Past, ... would + V1 — situasi hipotetis/tidak nyata sekarang.
  • "If I were" — bentuk baku Second Conditional untuk to be, dipakai untuk saran sopan.
  • Unless = "if not", jangan ditambah not lagi.
  • Jangan campur rumus — konsisten present+will atau past+would dalam satu kalimat.

13 Praktik

Percakapan — diskusi "what if" saat code review

Situasi: dua rekan kerja membahas pull request dan kemungkinan-kemungkinan yang bisa terjadi.

ReviewerIf this endpoint receives too many requests, will it crash?Kalau endpoint ini menerima terlalu banyak request, apakah dia akan crash?
KamuGood question. If we don't add rate limiting, it probably will.Pertanyaan bagus. Kalau kita tidak menambahkan rate limiting, kemungkinan besar iya.
ReviewerIf I were you, I would add a simple rate limiter before merging this.Kalau aku jadi kamu, aku akan menambahkan rate limiter sederhana sebelum merge ini.
KamuThat's fair. If I add it today, I will push the update by tonight.Itu masuk akal. Kalau aku tambahkan hari ini, aku akan push update-nya malam ini.
ReviewerPerfect. Unless something urgent comes up, I will approve it tomorrow.Sempurna. Kalau tidak ada yang mendesak, aku akan approve besok.
◆ Perhatikan

Perhatikan campuran First (if we don't add..., it probably will, if I add it today, I will push) dan Second (if I were you, I would add) dalam satu percakapan — keduanya dipakai secara natural tergantung apakah membahas rencana nyata atau saran/andaian.

14 Praktik

Writing exercise

Tulis 5 kalimat tentang pekerjaanmu, wajib memakai minimal 2 First Conditional dan 2 Second Conditional (boleh campur urutannya). Contoh kerangka:

  • Rencana nyata minggu ini — "If [syarat realistis], I will ..."
  • Risiko yang mungkin terjadi — "Unless [syarat], we will ..."
  • Andaian/saran ke rekan kerja — "If I were [posisi/orang], I would ..."
  • Situasi hipotetis tentang proyekmu — "If [sesuatu yang belum tentu terjadi], I would ..."
  • Bebas, boleh gabungan First & Second.
◆ Kirimkan hasilnya

Kirimkan hasil tulisanmu di chat kapan saja — akan dikoreksi konsistensi rumus (present+will vs past+would) dan kealamian kalimat sebelum kamu lanjut ke Materi 5.

15 Praktik

Speaking exercise

Ucapkan keras-keras (boleh rekam suara sendiri untuk didengar ulang):

  1. "If [rencana kerjamu] happens today, I will [langkah selanjutnya]."
  2. "Unless [risiko], we will [rencana cadangan]."
  3. "If I were [posisi orang lain — the lead/the manager], I would [saranmu]."
  4. "If I had more time this week, I would [hal yang ingin kamu lakukan tapi belum sempat]."

Fokus bukan pada kecepatan, tapi kejelasan kontraksi I'll, I'd, won't, dan wouldn't saat diucapkan santai (lihat bagian Pronunciation berikutnya).

17 Perkaya bacaan

Reading recommendation

"If the team completes the migration this quarter, we will save significant infrastructure costs. However, if the legacy system were replaced too quickly, we would risk breaking critical workflows that depend on it. Unless we test thoroughly, unexpected issues will appear in production. If I were leading this project, I would prioritize a gradual rollout instead of a full switch."

Paragraf perencanaan proyek ini sengaja dipadatkan dengan First & Second Conditional supaya kamu langsung latihan mengenali polanya dalam teks utuh, bukan cuma kalimat lepas.

Kalau sudah lancar, coba baca bagian "Risks" atau "Alternatives Considered" dari technical design document (RFC/ADR) project mana pun — biasanya penuh conditional: "If we choose option A, ... If we had chosen option B, we would ..."

19 Perkaya ucapan

Pronunciation tips

  • will /wɪl/ — dalam kalimat cepat, sering dikontraksi jadi 'll, hampir tidak terdengar sebagai suku kata terpisah. "I'll bring it."
  • would /wʊd/ — dikontraksi jadi 'd, mirip bunyi "d" pendek yang ditempel ke kata sebelumnya. "I'd learn it." Hati-hati: I'd bisa berarti "I would" ATAU "I had", bedanya ditebak dari kata setelahnya.
  • were /wɜːr/ — bunyinya seperti "wer" pendek, bukan "were" dieja huruf per huruf. Sering muncul dalam frasa cepat "if I were" — /ɪf aɪ wɜːr/.
◆ Contraction (kependekan)

Dalam kalimat natural: will → 'll (I'll, we'll, they'll), will not → won't, would → 'd (I'd, you'd), dan would not → wouldn't. Untuk speaking santai, pakai bentuk kontraksi ini. Untuk tulisan formal (email kerja, dokumentasi teknis), bentuk penuh lebih disukai — terutama saat menuliskan kondisi/syarat yang penting supaya tidak ambigu.

  • Hafal rumus If + Simple Present, ... will + V1 untuk First Conditional.
  • Hafal rumus If + Simple Past, ... would + V1 untuk Second Conditional.
  • Bisa memilih conditional yang tepat berdasarkan seberapa realistis syaratnya.
  • Kenali & hindari 4 kesalahan umum di bab 08, terutama soal mencampur rumus.
⚙ Middle

Praktikkan di kehidupan nyata

Setelah hafal rumus, pindahkan ke situasi asli — bukan cuma soal latihan.

  • Pakai First Conditional saat membahas rencana sprint yang masih realistis.
  • Pakai "if I were you" saat memberi masukan di code review.
  • Latih dengar lewat rekomendasi di bab Listening (rekaman sprint planning, podcast bisnis).
  • Coba kenali pola conditional di bagian "Risks" dokumen desain teknis (RFC/ADR).
🚀 Advance

Arah belajar lanjut

Setelah checklist Materi 4 tuntas, ini yang menanti untuk menutup Level 3.

  • Materi 5 — Linking Words & Connectors (because/although/however/so/therefore), materi terakhir Level 3.
  • Setelah Materi 5 tuntas, lanjut ke Cerita Hari Ini Level 3 — gerbang menuju Level 4.
  • Mulai biasakan membuat kalimat "what if" sendiri saat mendiskusikan rencana kerja, walau singkat.
  • Simpan istilah Third Conditional di kepala — itu menanti di Level 4, untuk membahas penyesalan/andaian masa lalu.
Penutup

Menimbang kemungkinan, bukan cuma menyatakan fakta

Materi 4 Level 3 selesai — conditional memang butuh latihan lebih untuk membedakan "masih mungkin" dan "cuma andaian", tapi kemampuan ini penting banget untuk merencanakan, bernegosiasi, dan memberi saran di dunia kerja software engineering. Jangan buru-buru; pastikan checklist di bab Review benar-benar tuntas.

  • First Conditional — If + present, will + V1 — kemungkinan nyata di masa depan.
  • Second Conditional — If + past, would + V1 — andaian/hipotetis, tidak nyata sekarang.
  • If I were you — cara sopan memberi saran, dipakai luas dalam code review.
  • Latih di dunia nyata — sprint planning, risk assessment, code review, negosiasi.
