Slow Query

Satu query lambat bisa menahan koneksi, menumpuk antrean, dan bikin seluruh aplikasi ikut lambat.

$ Cari satu nama di buku telepon tanpa urutan abjad.

penyebab

Kenapa query jadi lambat?

penyebab

Tidak ada index

Database membaca seluruh tabel (full scan).

penyebab

Fungsi di kolom WHERE

WHERE LOWER(email) = ... bikin index tidak terpakai.

penyebab

Ambil kebanyakan

SELECT * dan tanpa LIMIT.

penyebab

Data makin besar

Dulu 1.000 baris cepat, sekarang 10 juta.

cara cek

Tanya database: kamu ngapain sih?

✗ Full scan (lambat)
EXPLAIN SELECT * FROM orders
WHERE customer_id = 42;

-- Seq Scan on orders
-- rows=5000000   ← baca semua!
✓ Pakai index (cepat)
CREATE INDEX idx_orders_customer
  ON orders(customer_id);

-- Index Scan using idx_orders_customer
-- rows=12   ← langsung ketemu
EXPLAIN = minta database menunjukkan rencana kerjanya.
kebiasaan baik

Kebiasaan supaya query tetap cepat

  • Nyalakan slow query log (misal > 500ms) dan cek rutin.
  • Index kolom yang sering ada di WHERE, JOIN, dan ORDER BY.
  • Ambil kolom yang perlu saja, dan selalu pakai LIMIT.
  • Jangan kebanyakan index: tiap index bikin INSERT/UPDATE lebih lambat.
