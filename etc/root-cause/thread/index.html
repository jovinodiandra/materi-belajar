contoh

Bikin thread terus vs pakai pool

✗ Thread baru per tugas
for (Email e : emails) {
  new Thread(() -> kirim(e)).start();
  // ← 100.000 email = 100.000 thread
}
✓ Thread pool terbatas
ExecutorService pool =
  Executors.newFixedThreadPool(20);

for (Email e : emails) {
  pool.submit(() -> kirim(e));
} // ← maksimal 20 jalan bersamaan
Tiap thread makan memori (±1MB stack). Batasi jumlahnya.
