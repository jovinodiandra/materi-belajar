Resumable

lanjutkan, bukan ulang dari awal

◆ Buat apa ini? Kenapa pakai ini?

Given — halaman dirender di server lalu dikirim ke browser.

When — browser harus menjalankan ulang semua komponen (hydration) sebelum interaktif.

Then — halaman terlihat siap tapi belum bisa dipakai.

→ makanya kita pakai Qwik — supaya halaman langsung interaktif tanpa hydration.

warm-up

Apa itu hydration, versi gampang?

Bayangin rumah contoh di pameran properti.

  • Server mengirim rumah jadi (HTML) — kelihatan lengkap.
  • Tapi listrik belum nyala: saklar belum berfungsi.
  • Hydration = memasang ulang semua kabel listrik sebelum satu saklar pun bisa dipakai.
ide dasar

Komponen Qwik

export const Counter = component$(() => {
  const count = useSignal(0);

  return (
    <button onClick$={() => count.value++}>
      Klik: {count.value}
    </button>
  );
});
// kode onClick$ baru diunduh saat tombol diklik

Gampangnya

  • Tanda $ = titik di mana kode boleh ditunda.
  • Handler klik baru diunduh saat diklik.
  • Tidak ada hydration di awal.
Tanda $ = “kode ini boleh dimuat nanti”.

tanda $

Tanda $ = boleh dimuat belakangan

komponen
export const AddToCart = component$(({ id }) => {
  const added = useSignal(false);
  return (
    <button onClick$={async () => {
      await addToCart(id);
      added.value = true;
    }}>
      {added.value ? "✓ Ditambahkan" : "Beli"}
    </button>
  );
});
