CDN

Content Delivery Network: salinan file situsmu disimpan di server-server di seluruh dunia, supaya user mengunduh dari yang paling dekat.

$ Minimarket di tiap kecamatan, bukan satu gudang pusat.

Server di Jakarta. User di Papua menunggu 3 detik hanya untuk gambar.

🌏

Jarak itu nyata

Data butuh waktu untuk menempuh ribuan kilometer.

🏋️

Server asal kewalahan

Semua gambar & JS diminta ke satu server.

💥

Lonjakan trafik

Kampanye viral menjatuhkan server.

Simpan dekat user

salinan file di banyak lokasi

◆ Buat apa ini? Kenapa pakai ini?

Given — user mengakses situs dari banyak kota dan negara.

When — semua file dikirim dari satu server asal.

Then — situs lambat untuk user yang jauh dan server asal kewalahan.

→ makanya kita pakai CDN — supaya file dikirim dari lokasi terdekat dengan user.

praktik

Checklist CDN

  • File statis pakai nama ber-hash + cache panjang.
  • index.html pakai no-cache supaya selalu cek versi baru.
  • Respons milik user: private, no-store.
  • Siapkan cara purge (hapus cache) untuk keadaan darurat.
