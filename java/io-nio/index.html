ide dasar

Gaya lama vs gaya modern

✗ Gaya lama (java.io)
BufferedReader r = new BufferedReader(
    new FileReader("data.txt"));
String line;
while ((line = r.readLine()) != null) {
    process(line);
}
// lupa r.close()? file tetap terbuka
✓ Gaya modern (java.nio)
Path path = Path.of("data.txt");
try (Stream<String> lines =
         Files.lines(path, UTF_8)) {
    lines.forEach(this::process);
}   // otomatis ditutup

String small = Files.readString(path, UTF_8); // file kecil
Selalu: try-with-resources + tulis UTF-8 secara eksplisit.

Pilih cara sesuai ukuran

SituasiPakaiKenapa
File kecil (config, template)Files.readString / writeStringPaling simpel
File besar, per barisFiles.lines / BufferedReaderHemat memori
File biner besarInputStream + buffer / FileChannelBaca per potongan
Banyak koneksi jaringanNIO non-blocking / virtual threadSatu thread tidak menunggu satu koneksi
File kecil → readString. File besar → baca per baris/potongan.

Tidak ditutup

Path ditulis manual

"folder\\file" gagal di Linux. Pakai Path.of("folder", "file").

Encoding default

Tiap server bisa beda. Tulis UTF_8.
