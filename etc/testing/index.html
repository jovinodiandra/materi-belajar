Testing

Test itu robot kecil yang mengecek kode kita setiap kali ada perubahan. Biar kita berani mengubah kode tanpa takut.

$ Sabuk pengaman: bukan buat dipakai saat tabrakan saja, tapi biar berani jalan.

Tiga jenis test utama

JenisNgetes apaKecepatanJumlah
UnitSatu fungsi / class sendirianSangat cepatPaling banyak
IntegrationBeberapa bagian bareng (misal + database)SedangSecukupnya

contoh

Pola Given–When–Then

✗ Test yang susah dibaca
@Test void test1() {
  var s = new Cart();
  s.add(new Item(10000), 2);
  assertEquals(20000, s.t());
}
✓ Jelas maksudnya
@Test
void totalDihitungDariHargaKaliJumlah() {
  // given
  Cart cart = new Cart();
  // when
  cart.add(new Item(10_000), 2);
  // then
  assertEquals(20_000, cart.total());
}
Nama test = kalimat yang menjelaskan perilaku yang diharapkan.

test double

Stub, mock, fake: apa bedanya?

contoh
// STUB: memberi jawaban siap
when(rates.get("USD")).thenReturn(16_000);

// MOCK: mengecek dipanggil atau tidak
verify(mailer).send(eq("budi@x.com"), any());

// FAKE: versi sederhana yang bekerja
var repo = new InMemoryOrderRepository();
kapan pakai
Stub  → butuh input dari dependency
Mock  → hasilnya adalah 'efek samping'
        (email terkirim, event terbit)
Fake  → banyak interaksi,
        lebih mudah dibaca

Jangan mock semua hal.
Terlalu banyak mock = test yang hanya mengulang implementasi.
