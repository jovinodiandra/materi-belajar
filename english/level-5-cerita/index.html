Rangkum perjalananmu, secara profesional.

Ini bukan sekadar gerbang ke level berikutnya — tidak ada Level 6. Halaman ini adalah ujian akhir dari seluruh notebook, mulai dari Level 0 (Fondasi Nol) sampai Level 5 (Advance) yang baru saja kamu selesaikan. Tulis satu refleksi utuh dalam register formal/profesional, gabungkan semua yang sudah kamu kuasai: advanced modals, inversion/emphatic structure, subjunctive, cohesive devices, dan kosakata akademis — lalu pastikan bersih dari kesalahan grammar.

◆ Topik — Refleksi Profesional

Tulis sebuah professional reflection — boleh tentang perjalanan belajar Bahasa Inggris-mu di seluruh notebook ini dari Level 0 sampai sekarang, atau tentang sebuah proyek software engineering nyata yang baru saja rampung kamu kerjakan (retrospective, post-mortem, atau laporan singkat ke atasan/klien). Gunakan register formal-akademis: hindari bahasa gaul, singkatan tidak baku, atau nada terlalu santai.

Tunjukkan penguasaan grammar tingkat lanjut yang sudah kamu pelajari di Level 5: advanced modal untuk berspekulasi tentang masa lalu (must have, should have, might have, can't have), dan minimal satu inversion / emphatic structure (Never have I…, Not only did…, It was … that…, Had we known…, dsb).

◆ Referensi struktur (boleh dimodifikasi, jangan disalin mentah)
  • Advanced modal: "The regression must have been introduced during the last refactor." / "We should have written integration tests earlier." / "They might have underestimated the migration's complexity."
  • Inversion / emphatic: "Never have I worked on a project with such tight deadlines." / "Not only did the team deliver on time, but it also improved test coverage." / "It was the code review process that ultimately prevented a costly outage." / "Had we anticipated the traffic spike, the incident could have been avoided."
  • Subjunctive / hedging: "If only we had allocated more time for QA." / "It is recommended that the team adopt stricter linting rules." / "The results arguably suggest a need for further optimisation."
  • ✓ Minimal 12 kalimat
  • ✓ Pakai minimal 10 kata/frasa dari Rekap Vocabulary Level 5
  • ✓ Pakai minimal 1 struktur inversion / emphatic (Never have I…, It is/was … that…, dst)
  • ✓ Pakai minimal 1 advanced modal spekulatif (must have / should have / might have / can't have, dst)
  • ✓ Sudah dicek grammar & tidak ada kesalahan tersisa
